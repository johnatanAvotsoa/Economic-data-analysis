# 📊 Economic Data Analysis using FRED API

This project performs economic data analysis using the [FRED API](https://fred.stlouisfed.org/), provided by the Federal Reserve Bank of St. Louis. It demonstrates how to access, visualize, and analyze U.S. economic indicators (such as GDP, unemployment rate, CPI, etc.) in Python.

---

## 🚀 Features

- Fetch economic indicators using the FRED API
- Visualize time series data with Matplotlib and Seaborn
- Perform trend and correlation analysis
- Support for dynamic configuration via `.env` file
- Jupyter Notebook interface for interactive exploration

---

## 📦 Requirements

- Python 3.8+
- FRED API key (free, get one [here](https://fred.stlouisfed.org/docs/api/api_key.html))
